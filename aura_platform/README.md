## 🎯 Architectural Philosophy: Why One Unified Workbench?

In enterprise FinTech, financial operators and auditors need **One Central Operating Workbench** where:
* The data engine is fast, dense, and interactive (**AG Grid Community v31**).
* The AI intelligence is singular, structured, and deterministic (**Single AURA AI Brain**).
* All operations are cryptographically verifiable and require deterministic human sign-off (**AURA Cryptographic Warrant Gate**).

## 💎 Key Features Built for the Hackathon

### 1. Six Dynamic Multi-Intelligence Modes
Switching modes morphs the AG Grid columns, cell renderers, and filters without page reload:
* **Mode 1: 3-Way Reconciliation:** Real-time ledger matching (`PayPal Intake` vs `Internal Order` vs `General Ledger`). Automatically calculates discrepancy gaps and surfaces anomalies.
* **Mode 2: Risk Intelligence:** Anomaly scoring, geofencing, and biometric 2FA verification.
* **Mode 3: Disputes & Claims:** Chargeback tracking, countdown timers, and automated defense evidence assembly.
* **Mode 4: Refunds & Recoveries:** Automated overpayment recovery via PayPal Refund API rails.
* **Mode 5: Audit Trail:** Immutable log of cryptographic warrants, human co-signers, and sandbox receipts.
* **Mode 6: Transactions:** Real-time stream of incoming customer captures and agentic contractor payouts.

### 2. AG Studio Agent Framework & AI Assistant
Directly implementing the pattern demonstrated by James (Head of DevRel, AG Grid):
* **Data Agent:** Queries financial books in natural language (*"Which entity has the highest mismatch?"*, *"Who are our most loyal customers?"*).
* **Page / Action Agent:** Dynamically filters the AG Grid, highlights flagged rows, and triggers investigation drawers from prompt starters.
* **Prompt Starters:** 1-click executive questions for rapid judge evaluation.

### 3. Studio Cross-Filtering Ribbon
* Clicking any entity chip (*Enterprise Cloud Systems*, *Apex Health*, *Tokyo FinTech*) or discrepancy status instantly cross-filters the entire AG Grid table in 0ms.
* Shows calculated expressions: **Collection Rate (93.2%)**, **Platform Commission Yield (20.0%)**, and **Dual-Control Compliance (100%)**.

### 4. Unhappy Path Simulation Lab
Responding directly to Eddie (PayPal Developer Advocate)'s advice:
* **Webhook Timeout (408):** Demonstrates PayPal's 25-attempt exponential backoff retry protocol over 72 hours.
* **Rogue AI Drain Intercept (403):** An unauthorized agent attempts a $50,000 payout without human co-signing; vetoed by AURA Warrant Gate with **$0 funds moved**.
* **Split Mismatch (409):** Detects sub-merchant commission breaks before book closing.

### 5. 1-Click Flagship Reconciliation Benchmark (`REC-99420-FLAGSHIP`)
* 1-click run button auto-scrolls to the $5,000.00 marketplace commission discrepancy.
* AI Investigation Drawer diagnoses the exact cause (Vendor Escrow Rule MKT-04) with 99.4% confidence.
* Deterministic 1-click sandbox resolution settles the record, issues the SHA-256 warrant, and displays the verified PayPal receipt ticket.

## 🚀 Running the Workbench

### Preferred: Launch via Root Process Supervisor (All Services)
From the repository root:
```bash
python start.py
```

### Standalone Server Launch:
```bash
python run_server.py
```
Open **[http://127.0.0.1:8000](http://127.0.0.1:8000)** in your browser or view integrated inside AION at **[http://localhost:5173/aura](http://localhost:5173/aura)**.
